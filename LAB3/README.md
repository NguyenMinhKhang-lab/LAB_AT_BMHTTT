## Nội dung bài thực hành

LAB 3 tập trung vào việc nhận diện và ứng phó các mối đe dọa đến an toàn thông tin trên máy trạm Windows.

Các nội dung chính gồm:

- Phân biệt Asset, Vulnerability, Threat, Risk và Attack.
- Phân loại các nguồn đe dọa.
- Kiểm tra khả năng phát hiện mã độc bằng EICAR và Microsoft Defender.
- Quan sát các sự kiện đăng nhập bằng Windows Event Log.
- Phân tích nguy cơ Brute Force, Dictionary Attack và Keylogging.
- Nhận diện persistence và dịch vụ lắng nghe bằng Sysmon, Autoruns và Process Explorer.
- So sánh lưu lượng HTTP và HTTPS bằng Wireshark.
- Phân tích DoS, DDoS và Mail Bombing bằng dữ liệu thử nghiệm.
- Phân tích Social Engineering, Phishing và Spear Phishing.
- Cleanup hệ thống và kiểm tra tính toàn vẹn Evidence bằng SHA-256.
